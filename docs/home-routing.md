# Home = routing surface

Home exists to get the user **somewhere fast**, not to introduce the product.

## Jobs-to-be-done (in order)
- **Resume reading** from the last location
- **Jump** to a known passage (book/chapter/verse)
- **Browse canon** quickly (collection → book → chapter → verse)
- **Open study tools** (secondary)

## UI hierarchy (above the fold)
1. Minimal header (brand + minimal utilities)
2. Primary jump/search field
3. Continue reading / recent destinations (only when history exists)
4. Compact scripture collection grid (primary)
5. Compact study tools row (secondary)

## Rules
- If an element does not help route the user to content faster, **remove or demote it**.
- Orientation comes from **clear hierarchy + page titles + lightweight breadcrumbs + easy back**, not a persistent side rail.
- Cards are **functional**: scannable labels, compact spacing, clear tap targets.
